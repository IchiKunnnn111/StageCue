## Giới Thiệu

**StageCue Studio V6** là phần mềm điều khiển âm thanh sân khấu thiết kế riêng cho **nhạc kịch, kịch nói, văn nghệ, lễ hội và sự kiện trực tiếp**.

Thay vì phải mở nhiều cửa sổ nghe nhạc rời rạc dễ gây nhầm lẫn khi đang diễn, StageCue gom toàn bộ nhạc nền, tiếng động và lời thoại vào một **bàn điều khiển trực quan gọn sạch**, hỗ trợ bấm phím phát/dừng êm ái, chuyển cảnh mượt mà và khóa an toàn suốt buổi diễn.

## Tính Năng Nổi Bật

| Tính năng | Mô tả |
| :--- | :--- |
| **4 Trang Kịch — 40 Ô Nhạc (Clue)** | Chia kịch bản thành **4 Trang (`Trang 1..4`)**, mỗi trang 10 ô nhạc. Chuyển sang trang mới vẫn giữ nguyên nhạc đang chạy ở trang cũ, có thể đổi tên từng Hồi/Cảnh kịch. |
| **Chuyển Cảnh Mượt Tự Động** | Bật chế độ **`Mượt` (`Ctrl+X`)**: khi bấm phát bài nhạc nền mới, bài cũ đang chạy sẽ tự động nhỏ dần (Fade Out) để chuyển cảnh tự nhiên. Riêng các tiếng động đánh dấu **`SFX`** vẫn phát đè bình thường. |
| **Tự Động Fade In / Fade Out** | Nhạc vào êm ái, tắt nhỏ dần mượt mà và tự động nhỏ dần khi gần hết bài — không còn tình trạng âm thanh bị ngắt cụt bất ngờ trên sân khấu. |
| **Khóa Biểu Diễn Live (`Ctrl+L`)** | Khóa toàn bộ thao tác dễ bấm nhầm khi đang diễn (xóa nhạc, nạp đè file, thu âm, cắt nhạc, đổi phím, đổi màu), chỉ giữ lại các nút trình diễn an toàn. |
| **Đổi Tốc Độ & Tông Nhạc Trực Tiếp** | Tăng/giảm tốc độ phát (**`0.50x – 2.00x`**) và nâng/hạ tông nhạc (**`-6` đến `+6` bán cung**) ngay trong lúc đang phát để khớp nhịp diễn và giọng hát ca sĩ/diễn viên. |
| **Chọn Riêng Loa Sân Khấu, Tai Nghe & Mic (`F7`)** | Tách riêng **Loa Chính** phát ra hội trường và **Tai Nghe Nghe Thử** để kiểm tra bài trước trong cánh gà mà khán giả không nghe thấy; hỗ trợ chọn Mic thu âm trực tiếp vào ô Clue. |
| **Kiểm Tra Trước Giờ Diễn (`F6`)** | Tự động rà soát cả 40 ô nhạc trước giờ mở màn để báo file bị thiếu, trùng phím tắt hoặc âm lượng đang tắt; kèm **cảnh báo 10 giây cuối bài** ngay trên thanh phát. |
| **16 Màu Sân Khấu + 16 Triệu Màu Tự Chọn** | Phân loại từng ô nhạc bằng **16 tông màu nổi bật** hoặc tự phối **16 triệu màu RGB** (chuột phải lên ô Clue để đổi màu tức thì). Màu tự đồng bộ sang cả bàn Fader và thanh tua. |
| **Đặt Điểm Bắt Đầu / Dừng & Cắt Nhạc** | Chọn sẵn đoạn muốn phát **`[IN → OUT]`** kèm Fade mà không làm hỏng file gốc, hoặc cắt thẳng thành file mới có quay ngược nhiều bước. |
| **Tải Nhạc YouTube & Tách Nhạc Từ Video `.MP4` (`F5`)** | Dán link YouTube hoặc kéo thả trực tiếp file video **`.MP4`** vào ô Clue để phần mềm tự động chuyển thành file **`.MP3`** và nạp sẵn vào bàn điều khiển. |
| **Toàn Màn Hình & Giao Diện Laptop 13.3"** | Giao diện biểu tượng gọn gàng, 6 tông màu chủ đề (`F2`), hỗ trợ **Full Screen (`F11`)**, **Windowed Full Screen (`Alt+Enter`)** và tự căn chỉnh đẹp cho màn hình Laptop 13.3". |
| **Lưu Trọn Kịch Bản Trong 1 File `.kich`** | Đóng gói toàn bộ 4 Trang kịch, màu sắc, thứ tự phím, tốc độ/tông nhạc và tất cả file âm thanh vào **duy nhất 1 file `.kich`** để sao lưu hoặc gửi sang máy khác diễn ngay. |

## Phím Tắt Cơ Bản

| Phím tắt | Tác dụng |
| :--- | :--- |
| `1` – `9`, `0` | Phát / Dừng êm ái (Fade) cho 10 ô Clue trên Trang hiện tại |
| **Bấm đúp phím tắt** | Ngắt tiếng & dừng ngay lập tức tại chỗ |
| `TAB` | Chuyển bàn Fader & thanh tua giữa Cụm 1 (`1–5`) và Cụm 2 (`6–10`) |
| `Ctrl + 1..4` | Chuyển nhanh giữa 4 Trang kịch |
| `Ctrl + X` | Bật / Tắt Chuyển cảnh mượt tự động |
| `Ctrl + L` | Bật / Tắt Khóa biểu diễn Live |
| `ESC` | Dừng khẩn cấp toàn bộ âm thanh đang phát |
| `F1` | Mở hướng dẫn sử dụng ngay trong phần mềm |
| `F2` | Đổi nhanh 6 tông màu giao diện |
| `F3` | Ẩn / Hiện thư viện nhạc bên trái |
| `F5` | Tải nhạc YouTube / tách nhạc từ `.MP4` |
| `F6` | Kiểm tra toàn bộ kịch bản trước giờ diễn |
| `F7` | Chọn thiết bị Loa chính, Tai nghe nghe thử & Microphone |
| `F11` / `Alt + Enter` | Toàn màn hình / Toàn màn hình giữ thanh Taskbar |

## Cách Sử Dụng Nhanh

1. Tải **`StageCue_V6.zip`** ở mục **Releases** và giải nén.
2. Mở file **`StageCue.exe`** để chạy ngay (không cần cài đặt).
3. Kéo thả file nhạc (`.mp3`, `.wav`, `.m4a`, `.mp4`...) vào các ô **Clue** hoặc bấm **`F5`** để lấy nhạc từ YouTube.
4. Sắp xếp màu sắc, âm lượng, bấm **`F6`** kiểm tra trước giờ diễn và bật **`Ctrl+L`** để khóa an toàn khi lên sân khấu.
