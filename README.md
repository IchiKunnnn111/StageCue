## 🚀 StageCue Studio v1.0 — Final Release

### 📦 Nội dung gói tải về (`StageCue_Final_Release.zip`)
- `StageCue.exe` — Phần mềm chạy trực tiếp (Standalone, không cần cài đặt).
- `HUONG_DAN_SU_DUNG.txt` — Cẩm nang hướng dẫn chi tiết từng phím tắt & tính năng.
- `StageCue.ico` & `StageCue_Logo.png` — Bộ nhận diện thương hiệu StageCue.

### ✨ Tính năng trong phiên bản v1.0 Final
- **6 Clue Pads đa năng:** Hỗ trợ kéo thả file nhạc, thu âm trực tiếp (`● REC`), gán phím tắt tự do, bấm đúp Hotkey dừng khẩn cấp.
- **Hệ thống Fade Sân Khấu:** Tự động Fade In khi vào nhạc, Fade Out khi dừng và tự động Fade Out khi sắp hết bài; hỗ trợ chỉnh riêng từng Clue trong `⚙ Setting`.
- **Audio Trimmer (`✂ Cắt`):** Cắt trực tiếp file âm thanh gốc (giữ đoạn `IN → OUT` hoặc cắt bỏ đoạn giữa & nối file), xuất file đã cắt ra máy.
- **6 Giao diện Sân khấu (`🎨 Theme - F2`):** Chuyển đổi tức thì 6 tông màu chuyên nghiệp tối ưu cho hậu trường.
- **Đóng gói Preset (`.kich`):** Gộp toàn bộ thông số bàn diễn và 6 file âm thanh vào 1 file `.kich` duy nhất để di chuyển giữa các máy.
